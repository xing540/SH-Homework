# 小学四则运算题目生成与批改程序
## 项目简介
本程序为软件工程课程作业，使用Python3实现小学四则运算题目的自动生成、去重以及批量批改功能。
支持自然数、真分数、带分数；运算符包含 `+、−、×、÷`，单题最多3个运算符；
减法运算不会出现负数，除法运算结果为真分数；利用交换律实现加法、乘法题目去重；
完全手写递归下降表达式解析器，不使用eval函数，保证程序安全。

## 环境依赖
全部使用Python内置库，无需安装第三方包。Python版本 >=3.8

## 使用方式
### 1.生成题目
-n 指定题目数量，-r为必填参数，指定数字范围上限
```bash
python main.py -n 10 -r 10
